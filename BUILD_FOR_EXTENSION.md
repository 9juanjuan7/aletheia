# Building & Running Aletheia

## Quick Start

### Prerequisites

1. **Backend running**:

   ```bash
   cd backend
   python app.py  # Runs on http://localhost:5000
   ```

2. **Frontend built**:

   ```bash
   cd frontend
   npm run build  # Builds to frontend/dist/
   ```

3. **Copy to extension**:
   ```bash
   Copy-Item -Path "frontend\dist\*" -Destination "extension\dist" -Recurse -Force
   ```

### Load Extension in Chrome

1. Open `chrome://extensions/`
2. Enable **Developer Mode** (toggle in top-right)
3. Click **Load unpacked**
4. Select the `extension/` folder
5. Click the Aletheia icon on any health article
6. The sidebar opens and analyzes automatically

## Architecture

```
Extension Structure:
├── manifest.json          # Declares extension config
├── background.js          # Listens for icon clicks
├── sidebar/
│   ├── sidebar-react.html # React app loader
│   └── loader.js          # Loads React from dist/
└── dist/                  # Built React app (from frontend/dist/)

Flow:
1. User clicks extension icon
2. background.js sends URL/title message
3. React app (sidebar-react.html) loads and mounts
4. useExtensionMessage() hook receives the message
5. streamAnalysis() calls /analyze-stream endpoint
6. Backend analyzes and streams back results
7. UI displays findings
```

## File Organization

- **`backend/`** - Flask API (untouched, unchanged)
  - `app.py` - Main API server
  - `services/` - Analysis engine
  - `data/` - Cache files
- **`frontend/`** - React/Tailwind UI

  - `src/pages/Index.tsx` - Main entry point
  - `src/services/api.ts` - API client
  - `src/hooks/useExtensionMessage.ts` - Extension message listener
  - `dist/` - Built app (generated by `npm run build`)

- **`extension/`** - Chrome extension
  - `dist/` - Symlink to frontend build output
  - `sidebar/sidebar-react.html` - Extension sidebar HTML
  - `sidebar/loader.js` - Loads React from dist/

## Troubleshooting

**Blank sidebar?**

- Check extension console (right-click extension → Inspect)
- Ensure `frontend/dist/` exists (run `npm run build`)
- Ensure files copied to `extension/dist/`

**API errors?**

- Verify Flask backend running: `python app.py`
- Check it's at `http://localhost:5000`

**Module not found?**

- Rebuild: `cd frontend && npm run build`
- Recopy: `Copy-Item -Path "frontend\dist\*" -Destination "extension\dist" -Recurse -Force`
- Reload extension: `chrome://extensions/` → reload button
